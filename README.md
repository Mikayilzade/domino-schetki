# Домино — счётки

Мобильная PWA для счёта в живых партиях домино.

## Режимы

- **Обычное домино** — остаток камней записывается победителю, победа при 101+.
- **Телефон** — быстрые начисления +5…+35, остаток руки округляется вверх до 5, рука не пишется после 300, +35 до появления счёта 300 даёт мгновенную победу.
- **Qoşa açdı** — +10 штраф и −10 за завершение гошой, счёт не уходит ниже нуля, попытка сохраняется в истории.

## Возможности

- сохранённый список игроков;
- произвольное деление на команды;
- автоматическое сохранение партии;
- журнал действий и отмена последнего начисления;
- полноэкранная установка на iPhone и Android как PWA;
- работа офлайн после первого открытия.

## Запуск

Откройте `index.html` через любой локальный HTTP-сервер, например:

```bash
python -m http.server 8080
```

Затем перейдите на `http://localhost:8080`.

GitHub Actions намеренно не добавлены.
